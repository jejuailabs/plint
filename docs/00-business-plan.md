# 지번 하나로 끝내는 건축 사전검토 자동화 플랫폼

**VWorld · 공공 API · SketchUp MCP 연동 기반 — 대지분석부터 매스모델·사업성 분석까지**

> 사업 기획 (내부 검토용) | 2026.08.27

건축 프로젝트 초기 단계(대지분석 → 법규검토 → 매스스터디 → 사업성 분석)는 현재 전문 인력이 수일에서 수주 걸려 수행하는 고비용 병목 구간이다. 본 플랫폼은 지번 입력 하나로 VWorld·국토교통부·기상청 등 11개 공공 API에서 데이터를 자동 수집하고, 법규 규칙 엔진으로 건축 가능 범위를 산출한 뒤, SketchUp MCP를 통해 3D 매스모델까지 자동 생성한다. 기존 반나절~3일 소요 작업을 10분 이내로 단축하며, 건축사사무소·디벨로퍼·부동산 플랫폼 세 시장을 동시에 타깃한다.

---

## Problem — 건축 초기 검토는 왜 느린가

건축주가 "이 땅에 뭘 지을 수 있나"를 알기까지, 건축사는 다음을 모두 수작업으로 수행한다.

- 지적도 확인
- 토지이용계획원 열람
- 건축물대장 조회
- 용도지역별 건폐율·용적률 확인
- 일조권 사선·이격거리 계산
- 주변 현황 파악
- 매스 스케치

이 과정에서 참조하는 시스템만 5~7개이며, 데이터 포맷이 제각각이라 통합 분석에 시간이 소요된다. 소규모 사무소(1~5인)일수록 이 병목이 크고, 건축주는 상담비 50~100만원을 지불해야 기초 검토 결과를 받을 수 있다.

| 구분 | 소요 시간 |
|---|---|
| 현재 수작업 소요 시간 | **4~24시간** |
| 자동화 후 목표 시간 | **10분** |

---

## Solution — 자동화 파이프라인

지번 입력 한 번으로 4단계가 순차적으로 실행된다.

### Phase 1. 대지 정보 자동 수집
지번을 키로 11개 공공 API에 병렬 요청. 필지 형상·면적·용도지역·건축물대장·공시지가·실거래가·지형고도·항공사진·접도 조건·일사량을 일괄 수집하고, 통합 대지 정보 객체로 정규화한다.
- **소요:** ~5초 (현재 수작업 2~4시간)

### Phase 2. 법규 자동 검토
용도지역별 건폐율·용적률 한도, 높이 제한, 일조권 사선(정북·정남방향), 인접 대지 이격거리, 법정 주차 대수를 규칙 엔진으로 연산.
- **결과:** 최대 건축면적·연면적·층수·건물 엔벨로프 형상
- **소요:** ~2초 (현재 수작업 1~3시간)

### Phase 3. 3D 매스모델 자동 생성
SketchUp MCP를 통해 Ruby API로 모델링 명령 전송. 필지 위에 법규 엔벨로프를 반영한 건물 매스를 자동 생성하고, VWorld 3D 데이터로 주변 건물 컨텍스트를 함께 배치한다. 기존 건물이 있는 경우 건축물대장 기반 현황 모델도 생성.
- **소요:** ~3분 (현재 수작업 1~3일)

### Phase 4. 사업성 분석 리포트
최대 연면적 × 주변 실거래 시세로 예상 수익 산출. 용도별 표준 공사비 적용해 총사업비 추정. 토지 매입가 대비 수익률·IRR을 자동 계산하여 투자 판단 근거를 제공한다.
- **소요:** ~1초 (현재 수작업 별도 의뢰)

## Data Sources — 연동 공공 API · 데이터

> 외부 데이터의 실제 서비스 ID, 수집 방식, 라이선스와 추가 데이터 우선순위는 `08-open-api-product-expansion.md`를 구현 기준으로 삼는다. 아래 표의 11개 항목은 사용자에게 제공할 데이터 범주이며, 각각이 단일 REST API 호출을 의미하지 않는다.

| 수집 데이터 | 출처 | 제공 정보 |
|---|---|---|
| 필지 형상·면적 | VWorld 지적도 API | 경계 폴리곤(GeoJSON), 지목, 공부면적 |
| 용도지역·용도지구 | 토지이용규제정보서비스 | 용도지역명, 건폐율·용적률 한도, 중첩 규제 |
| 건축물 현황 | 건축HUB 건축물대장 API | 층수, 구조, 용도, 연면적, 준공연도, 주차 등 공개 속성 |
| 주변 건물 3D | GIS건물통합정보 + 건축물대장 | 풋프린트·층수/높이 기반 자체 LOD1 생성, VWorld 3D는 화면 참조 |
| 지형 표고 | DEM 타일/파일 + 토지특성정보 | 수치표고모델 사전 적재, 경사도 분석 및 정성 폴백 |
| 항공 영상 | VWorld 항공사진 | 고해상도 정사영상 (현장 사진 대용) |
| 도로·접도 | 도로중심선·도시계획도로·지적·토지특성 | 현황/계획도로 구분, 인접 도로 폭·접도 후보와 신뢰도 |
| 공시지가 | 국토부 공시지가 API | 개별·표준 공시지가, 연도별 변동 |
| 실거래가 | 국토부 실거래가 API | 매매·전월세 실거래, 주변 시세 |
| 일사량·기상 | 기상청 API | 일조 시간, 일사량, 풍향·풍속 |
| 주소·좌표 변환 | 도로명주소 API | 지번↔도로명↔좌표 상호 변환 |

### MCP 연동 레이어
상기 API 데이터는 Claude MCP 서버로 래핑하여 자연어 인터페이스를 제공한다. 사용자가 "서울시 강남구 역삼동 123-4 분석해줘"라고 입력하면, MCP 서버가 지번을 파싱하고, 11개 API에 병렬 요청 후 통합 결과를 반환한다. SketchUp MCP는 별도 프로세스로 모델링 명령을 중계한다.

## Market — 타깃 시장 및 상품화 시나리오

### Segment A. 건축주 · 디벨로퍼
토지 매입 전 개발 가능성을 전문가 없이 셀프 검토. 현재 건축사 상담비 50~100만원 대체.
- **과금:** 월 10~30만원 구독 또는 건당 과금

### Segment B. 건축사사무소 (1~5인)
초기 검토 자동화로 클라이언트 미팅 전 준비 시간을 대폭 단축. 대지분석서·법규검토서·매스모델 일괄 생성.
- **과금:** 월 20~50만원 프로 플랜

### Segment C. 부동산 · 투자 플랫폼
토지 매물 정보에 개발 가능성·예상 수익률을 자동 부착. B2B API 형태로 기존 플랫폼에 임베드.
- **과금:** API 콜 단위 과금 (건당 1,000~5,000원)

## Scope — 범위와 한계

**할 수 있는 것:**
규칙적·수치적 사전검토 자동화. 필지 데이터 수집, 법규 산술 검토, 박스형 매스모델 생성, 주변 맥락 시각화, 표준단가 기반 개략 사업성 분석.

**할 수 없는 것:**
실시설계 도면(평면·단면·상세도), 인허가 심의용 정밀 일조권 분석, 곡면·비정형 건축물 자동 설계, 지자체 조례 예외사항 100% 커버(지속적 업데이트로 대응).

> 플랫폼의 포지셔닝은 **"설계의 첫 10%를 자동화"**하는 것이며, 건축사의 전문적 판단을 대체하는 것이 아니라 판단을 위한 기초 자료를 빠르게 마련해주는 도구이다.
